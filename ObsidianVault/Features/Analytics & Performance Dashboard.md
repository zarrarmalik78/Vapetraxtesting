# Analytics & Performance Dashboard

## Overview
The Analytics & Performance Dashboard converts store transaction data into visual performance charts, revenue trends, top-selling categories, and profit margin breakdowns.

---

## ⚙️ Key Metrics & Charts

1. **Revenue vs Expense Trends**: Line charts tracking daily/weekly financial metrics.
2. **Top Category Breakdown**: Pie charts illustrating sales distribution across Devices, Coils, E-liquids, and Pods.
3. **Low Stock Warning List**: Real-time summary of products needing reorder.
4. **Payment Method Split**: Comparison between Cash, Card/Online, and Customer Credit volume.
